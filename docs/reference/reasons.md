| Kind | Conditions | Notable reasons |
| --- | --- | --- |
| `Tailnet` | `ApiReachable`, `ApiKeyValid`, `HeadscaleCompatible`, `PolicyMode`, `SplitDNS`, `UsersUnique`, `PolicyRendered`, `PolicyApplied`, `SpokesReady` (only with `policy.spokes[]`) | `Reachable` / `Unreachable` / `Unhealthy` (database down); `Valid` / `Rejected` / `Error`; `Compatible` / `Incompatible` / `CannotVerify` / `ProbeFailed`; `Database` / `File`; `Configured` / `Missing` / `Mismatch` (split zone read back from an agent's netmap and compared with the gateway LoadBalancer IP) / `CannotVerify` (no bound gateway or no online agent); `Unique` / `Duplicate` (two Headscale users share a name — every policy write is rejected until one is destroyed; `status.userConflicts` counts them) / `CannotVerify`; `Rendered`, `BaseMissing`, `BaseInvalid`, `PolicyEmpty` (refused: would lock everyone out), `FragmentMissing` / `FragmentInvalid` (a listed spoke fragment is absent, carries a non-additive block or steps outside the hub's limits — owners, approvers, allowlist, tcp ports, reserved networks; render fails closed, nothing written); `DryRun`, `InSync`, `Applied`, `HubMerged` / `HubPending` (spoke: the live policy carries all / not yet all of its exported entries; `status.policy.appliedHash` is set only when merged), `Export` (spoke: fragment rendered, control server not readable), `PolicyModeFile` (write skipped), `PolicyRejected` (Headscale refused; old policy stays), `ApplyFailed`, `NoAPIKey`; `AllMerged` / `SpokeUnreachable` / `SpokeFragmentInvalid` / `ApprovalPending` / `NothingApproved` (worst spoke wins; the per-spoke verdicts are in `status.spokes[].conditions`) |
| `TailnetEgress` | `TagKnown`, `Registered`, `RoutesGranted`, `TargetsReachable`, `Exposed` (only with `spec.expose`), `ServiceConflict`, `Ready` | `Known` / `Unknown` / `PolicyPending` (tag not in live policy yet); `Registered` / `NotRegistered` / `WorkloadBlocked` (agent pod refused by admission — LimitRange/quota/PodSecurity; message carries the admission text); `RoutesMissing`, `Unreachable`, `NameUnresolved` (a target name did not resolve — a tailnet-zone alias needs a `:53` split-DNS grant for the egress tag, or use the target's MagicDNS name `<hostname>.<base_domain>`), `ProbeFailed` (agent not scraped — NetworkPolicy or pod down; nothing is known about routes/dials); `Exposed`: `AddressAssigned` / `PendingAddress` (a target Service has no LoadBalancer address yet) / `Denied` (an `allowFrom` prefix is outside the Tailnet's `exposeSourceAllowlist`; rendered without the expose); `Conflict` (target name taken by a foreign Service); `Ready` false with `NoTailnet`, `NoAPIKey`, `TagUnknown`; with the failed step and its error in the message: `InvalidTag` / `InvalidHostname` (tag or rendered hostname invalid), `DNSConflictUnresolved` (the Tailnet's DNS claims could not be read), `PolicyUnreadable` (live policy not readable from Headscale), `AuthKey` (pre-auth key not minted or bound), `Apply` (agent workload not applied), `ListNodes` (Headscale nodes not listed); otherwise with the reason of the first blocking condition (`NotRegistered`, `RoutesMissing`, `ProbeFailed`, `Unreachable`, `PendingAddress`, `Denied`); per target `status.targets[].reason` ∈ `NotAdvertised`, `NotApproved` (re-approved by the operator on the next policy reconcile), `NoGrant`, `ProbeFailed`, `NameUnresolved` — empty for a reachable MagicDNS-named target, which has no route (`route` empty, `present` true) |
| `TailnetSite` | `RouteConflict`, `UnmanagedOverlap`, `Advertised`, `Approved`, `Ready` | `OverlapsReserved` / `OverlapsSite` (blocked, nothing rendered; the older site is untouched); `Unmanaged` (a node without an advertiser tag advertises an overlapping route — report only); `NotAdvertised` / `NotApproved` (exact-prefix match on advertiser nodes); `NotObserved` (control server not queried); `Ready` false carries the first blocking reason in the order `RouteConflict`, `Advertised`, `Approved` |
| `TailnetGateway` | `Registered`, `RoutesInSync`, `DNSReady`, `StaleNodes`, `ClusterDNSForward`, `WorkloadCurrent`, `ServiceReady`, `Ready` | `Suspended`; `Provisioning` / `FreshBlocked` / `IdentityChanged` / `FreshRuntimeReady` (Ready); `Approved` / `NotApproved` (routes); `PodCurrent` / `PodTemplateStale` / `WorkloadUpdateBlocked`; `LoadBalancerAssigned` / `LBPending`; `ExternallyManaged` (DNS forward, stale nodes) |
| `TailnetIngress` | `TagKnown`, `PolicyGranted`, `Registered`, `BackendsReachable`, `TLSReady`, `Ready` | as egress, plus `Granted` / `PolicyDenied` (`allowFrom` outside the allowlist) / `SourceTagUnknown` (an `allowFrom` `tag:` source is not declared in the live tailnet policy — the other sources stay granted and the ingress becomes reachable from that tag once it exists; `Ready=False` meanwhile), `InvalidDNSName`, `DNSNameConflict` (an older CR already claims a name/alias), and for `mode: http` the `TLS*` reasons ([Terminate TLS on the agent](../how-to/ingress-https.md#terminate-tls-on-the-agent)), among them `TLSChainInvalid` (the served leaf does not verify against the Secret's `ca.crt` — a foreign issuer or a name outside the issuing CA's name constraints; the agent keeps serving the leaf, only the status reports it; absent `ca.crt`, no chain check runs), and `BridgeNameDenied` (a `bridgeNames` entry outside every `Tailnet.spec.bridgeNameAllowlist` zone, the zone itself, or inside the tailnet name/alias zone — [Bridge names](../how-to/ingress-https.md#bridge-names)); `Ready` false also with `WorkloadMigrationBlocked` / `HTTPTransitionBlocked` (the previous agent workload could not be retired; the message carries the error), otherwise it carries the first blocking reason in the order `Registered`, `PolicyGranted`, `TLSReady`, `BackendsReachable` |

`Tailnet.status.spokes[]` (hub with `policy.spokes[]`) = `{name, fetchedHash, fetchedAt, approvedHash,
approvedAt, pendingHash, pendingSince, pendingDelta{tagsAdded,…,routesRemoved}, conditions}` with
`SpokeReachable` (`Reachable` / `Unreachable` — network, or the operator's own NetworkPolicy without
`networkPolicy.spokePeers`/`spokeCIDRs` / `Forbidden` / `KubeconfigMissing` / `KubeconfigInvalid`), `SpokeFragmentValid` (`Valid` / `FragmentInvalid` / `FragmentMissing` /
`Unknown` — nothing fetched) and `SpokeFragmentApproved` (`Auto`, `Approved`, `ApprovalPending` — a
newer valid fetch waits for the annotation, `ApprovalStale` — the annotation names a hash that is no
longer the pending one, `NothingApproved` — `Manual` spoke whose first fetch was never approved).
Events `SpokeFragmentAdopted` (Auto) and `SpokeFragmentApproved` (Manual) name the hash that went
live.
`Tailnet.status.policy` = `{renderedHash, appliedHash, appliedAt, generated{tags,grants,routes}}`;
`TailnetIngress.status.dnsName` is the ingress-level DNS name; HTTP names and aliases appear in
`status.exposes[].dnsName` and `.dnsAliases`. All are published as A records with the node's IPv4
address; `status.tag` is the effective tag. `kubectl get tailnet` includes `COMPAT` and `DNS` reason columns.
Preflight uses the API response shape, not a reported server version: database policy mode and a
successful non-mutating `policy/check` probe are required for `Compatible`. Missing or failed
observations stay `Unknown`. See [preflight details](../how-to/install-headscale.md#preflight).
Event `PolicyDriftOverwritten` fires when
the live policy was changed behind the operator's back and rewritten. Event `ConfigMapNotOwned`
fires when a hosts or rendered/fragment ConfigMap of the configured name is controlled by another
resource (an ownerRef-less one carrying the operator's `tsunaro.io/role` label is re-adopted instead).
